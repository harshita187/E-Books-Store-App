# E-Books Store App

A React-based e-commerce style application designed and developed to
browse and explore e-books. The project focuses on building a complete
frontend experience using modern React concepts, clean component
structure, and effective state management.


## Features
- Browse e-books by category
- Search e-books by title
- User authentication flow
- Add to cart functionality
- Responsive UI for different screen sizes

## Tech Stack
- React
- JavaScript
- Context API
- Tailwind CSS
- JSON Server

## What I Learned
- React component architecture and props flow
- State management using Context API
- Handling user interactions and conditional rendering
- Building reusable UI components
- Working with mock APIs and authentication flow
